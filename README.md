一款轻量级 Windows 文件管理器，采用四象限布局，支持多标签页、书签管理和 UNC 网络路径访问。

## 功能特性

- **四象限布局** — 同时浏览四个目录，提高工作效率
- **多标签页** — 每个象限独立标签页，支持新建/关闭/切换、历史记录导航
- **书签管理** — 支持分组、拖拽排序、导入/导出
- **面包屑导航** — 分段路径显示，点击跳转到任意父目录
- **文件操作** — 复制、剪切、粘贴、删除、重命名，支持跨象限文件拖拽
- **视图切换** — 详细信息/大图标/小图标/列表/平铺五种视图模式
- **新建文件** — 支持创建 txt/md/py/bat/ps1/c/h 及 Office 文档（docx/xlsx/pptx）
- **自定义命令** — 可配置快捷命令菜单，支持占位符替换
- **系统集成** — 原生右键菜单，带超时保护避免第三方 Shell 扩展卡死主窗口
- **UNC 网络路径** — 支持 `\\server\share` 路径访问，异步可达性检查
- **目录监控** — 文件变化自动刷新（基于 `ReadDirectoryChangesW`）
- **设置对话框** — 会话恢复、默认路径、自动更新等选项
- **状态持久化** — 自动保存窗口布局、标签页状态和视图设置
- **崩溃保护** — VEH/UEH 异常捕获 + 看门狗卡死检测，自动生成 minidump
- **自动更新** — 支持从 GitHub 检查并下载新版本

## 使用

直接运行 `DQuad.exe` 即可。

### 快捷键

| 按键 | 功能 |
|------|------|
| `Ctrl+T` | 新建标签页 |
| `Ctrl+W` | 关闭标签页 |
| `Ctrl+D` | 添加当前路径到书签 |
| `Ctrl+B` | 显示/隐藏书签面板 |
| `Ctrl+C/X/V` | 复制/剪切/粘贴 |
| `Ctrl+A` | 全选 |
| `F2` | 重命名 |
| `F5` | 刷新 |
| `Del` | 删除到回收站 |
| `Shift+Del` | 永久删除 |
| `Enter` | 打开选中文件/目录 |
| `Alt+F4` | 退出 |

### 鼠标操作

| 操作 | 区域 | 功能 |
|------|------|------|
| 双击标签页 | 标签栏 | 关闭该标签页 |
| 单击空白处 | 标签栏 | 新建标签页 |
| 双击文件 | 文件列表 | 用系统默认程序打开 |
| 双击文件夹 | 文件列表 | 进入该文件夹 |
| 双击空白处 | 文件列表 | 返回上级目录 |
| 拖拽文件 | 跨象限 | 跨象限文件拖拽 |
| 拖拽书签 | 书签树 | 移动书签到分组 |

## 配置

配置文件位于程序目录，UTF-8 编码的 INI 格式：

| 文件 | 说明 |
|------|------|
| `state.ini` | 窗口位置、象限路径、标签页状态、更新配置、提示已读状态 |
| `bookmarks.ini` | 书签树结构（分组 + 项） |
| `commands.ini` | 工具栏菜单的自定义命令 |

### 设置对话框

通过菜单 `工具 → 选项` 打开设置对话框，可配置：

| 分类 | 选项 |
|------|------|
| 常规 | 启动时恢复上次会话、新标签页默认路径（桌面/我的电脑/自定义）、命令配置文件管理 |
| 更新 | 自动检查更新开关、检查间隔（天）、立即检查更新 |

### 自定义命令

点击工具栏终端按钮弹出命令菜单，命令按 `commands.ini` 配置执行。

菜单入口：`文件 → 打开命令配置文件`

支持占位符：

| 占位符 | 说明 |
|--------|------|
| `{cwd}` | 当前标签目录 |
| `{sel}` | 当前列表首个选中项完整路径（无选中时为空） |
| `{name}` | `{sel}` 的文件名（无选中时为空） |

命令配置示例：

```ini
[Command0]
name=Code 打开当前目录
program=code
args="{cwd}"
scope=cwd
confirm=0
enabled=1
```

安全策略：`confirm=1` 时强制执行前确认；未强制确认时，若命令包含高风险关键词（`del`、`rd`、`format` 等）也会弹确认。

## 构建

### 依赖

- **编译器**: MinGW-w64 (GCC)
- **系统**: Windows 7+

### 编译

```powershell
# Debug 构建（含调试符号和 -fanalyzer）
.\scripts\build.ps1

# Release 构建（-Os 优化）
.\scripts\build.ps1 -Configuration Release
```

### 静态分析

```powershell
# clang-tidy 检查
.\tests\clang-tidy\tidy.ps1

# Cppcheck 检查（含 MISRA C 规则）
.\tests\cppcheck\cppcheck_run.ps1
```
