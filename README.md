一款轻量级 Windows 文件管理器，采用四象限布局，支持多标签页和书签管理。

## 功能特性

- **四象限布局** — 同时浏览四个目录，提高工作效率
- **多标签页** — 每个象限独立标签页，支持新建/关闭/切换/拖拽排序
- **书签管理** — 支持分组、拖拽排序、导入/导出
- **面包屑导航** — 快速跳转到任意父目录
- **文件操作** — 复制、剪切、粘贴、删除、重命名
- **视图切换** — 支持详细信息/大图标/小图标/列表/平铺五种视图模式
- **环境变量快捷设置** — 工具栏一键打开系统环境变量配置界面
- **文件拖拽** — 支持跨象限文件拖拽操作
- **自定义命令** — 可配置快捷命令菜单，支持占位符替换
- **系统集成** — 右键菜单支持系统原生操作
- **状态持久化** — 自动保存窗口布局、标签页状态和视图设置

## 使用

直接运行 `DQuad.exe` 即可。

### 快捷键

| 按键 | 功能 |
|------|------|
| `Ctrl+T` | 新建标签页 |
| `Ctrl+W` | 关闭标签页 |
| `Ctrl+D` | 添加当前路径到书签 |
| `Ctrl+C/X/V` | 复制/剪切/粘贴 |
| `Ctrl+A` | 全选 |
| `F2` | 重命名 |
| `F5` | 刷新 |
| `Del` | 删除到回收站 |
| `Shift+Del` | 永久删除 |
| `Enter` | 打开选中文件/目录 |
| 双击标签页 | 关闭该标签页 |
| 双击列表空白处 | 返回上级目录 |
| 单击标签栏空白处 | 新建标签页 |

## 配置

配置文件位于程序目录，UTF-8 编码的 INI 格式：

| 文件 | 说明 |
|------|------|
| `bookmarks.ini` | 书签树结构（分组 + 项） |
| `state.ini` | 窗口位置、象限路径、标签页状态 |
| `commands.ini` | 工具栏菜单的自定义命令 |

### 自定义命令

点击工具栏终端按钮弹出命令菜单，命令按 `commands.ini` 配置执行。

菜单入口：`文件 → 打开命令配置文件`

支持占位符：

| 占位符 | 说明 |
|--------|------|
| `{cwd}` | 当前标签目录 |
| `{sel}` | 当前列表首个选中项完整路径（无选中时为空） |
| `{name}` | `{sel}` 的文件名（无选中时为空） |
